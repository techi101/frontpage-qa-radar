BUG-1 · Footer “Refunds” link opens “Post not found” OpenTest pinned

Home → footer → Refunds (/s/refunds) shows the feed with “Post not found”, titled “Post refunds | Trading Discussion”. Terms, Privacy and About load fine. Several 1-star reviews are about auto-debit and refunds, so this page matters.

BUG-2 · /sitemap.xml is an HTML “Stock Not Found” page OpenTest pinned

The stock-symbol route catches it. Search engines get no sitemap for the stock and club discussion pages, and robots.txt has no Sitemap line.

BUG-3 · Unknown URLs return 200, not 404 OpenTest pinned

Any typo URL becomes an indexable “Stock Not Found” page (a soft 404).
